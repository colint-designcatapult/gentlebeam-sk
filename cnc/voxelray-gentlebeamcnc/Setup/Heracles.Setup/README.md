# Installers: HowTo

## Requirements

Installers are built using NSIS (Nullsoft Scriptable Install System).
Please download it from https://sourceforge.net/projects/nsis/ and install it to the default installation folder ("C:/Program Files (x86)"".

## Building an installer

To build Heracles installer, just run "Build project" on Heracles.Installer.
The resulting installer executable will be put into the Heracles.Installer/bin folder.
